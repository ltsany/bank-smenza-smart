Bantuan

Temukan panduan cepat dan solusi umum. Jika masih butuh bantuan, kirim pesan lewat formulir di samping.

Bagaimana Cara Top Up?

Login → pilih Top Up → isi data & unggah bukti → konfirmasi admin. Gunakan QRIS atau transfer bank.

  1. Login ke akunmu
  2. Pilih menu Top Up
  3. Isi nominal & unggah bukti
  4. Tunggu verifikasi admin

Kenapa Top Up Gagal?

Beberapa penyebab umum: saldo pengirim kurang, koneksi tidak stabil, atau bukti pembayaran tidak valid.

  • Saldo rekening utama tidak mencukupi
  • File bukti tidak terbaca / format salah
  • Sistem sedang maintenance

Bagaimana Cek Saldo?

Login → pilih MySaving atau menu Cek Saldo. Saldo dan riwayat transaksi akan tampil real-time.

Jika ada selisih, hubungi admin agar dilakukan klarifikasi.
